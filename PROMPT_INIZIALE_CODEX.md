# Prompt iniziale per Codex — Ufficio Regali

Devi implementare il sito web **Ufficio Regali**, partendo dal file `BLUEPRINT_UFFICIO_REGALI_v1.md`, che è la fonte di verità per requisiti, tono, copy, storyboard, dati, stack, criteri di accettazione e milestone.

## Istruzioni operative

1. **Leggi interamente il blueprint prima di generare codice.** Identifica requisiti approvati, non-obiettivi e decisioni lasciate aperte.
2. **Implementa solo M0 e M1 nella prima iterazione**: progetto Vite + React + TypeScript, design tokens, header, hero, indagine, archivio placeholder, metodologia e footer, mobile-first e responsive. Non iniziare il 3D nella prima iterazione.
3. In assenza di repository esistente, crea il progetto nella directory di lavoro corrente. Se esiste già codice, esaminalo e preserva file e configurazioni non pertinenti.
4. Il testo del sito deve seguire il copy baseline; **non inventare nuovi inside joke** né libri reali o link Amazon.
5. Ogni sezione deve avere layout curato anche su 360px di larghezza, viewport desktop 1440px, zoom 200% e `prefers-reduced-motion`.
6. Usa CSS nativo con design tokens; evita dipendenze pesanti e backend. Configura il deploy GitHub Pages con `base` parametrizzabile per il repository reale.
7. Aggiungi script npm `dev`, `build`, `preview`, `lint`, `test`; configura test significativi per le funzionalità presenti.
8. Esegui e riporta realmente i controlli disponibili; non affermare che test o deploy passino senza averli eseguiti.
9. A fine milestone fornisci: file modificati, scelte implementative, screenshot o descrizione verificabile delle viste mobile/desktop, test eseguiti, problemi noti e checklist di accettazione.
10. **Attendi l'istruzione successiva per M2** e seguenti, rispettando l'ordine del blueprint. Non integrare Bookly finché non hai il repository/codice pertinente.

## Prima consegna richiesta

Una **homepage React responsive realmente avviabile** con identità UR., copy coerente, navigazione funzionante tra sezioni e catalogo placeholder chiaramente dimostrativo; pronto per aggiungere il carosello in M2–M3.

**Vincolo assoluto:** l'interfaccia deve sembrare un elegante microbrand editoriale/istituzionale, non un template generico, non un sito meme, non un e-commerce tradizionale.
